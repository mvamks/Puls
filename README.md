# Puls 🚴‍♀️

Проект одностраничного сайта фитнес-студии. Используется Gulp для сборки, Sass для стилей, jQuery и сторонние библиотеки для UI-анимаций и слайдера.

---

## 📷 Демонстрация

🔗 [GitHub Pages](https://mvamks.github.io/Puls/)  

---

## 🚀 Как запустить проект

### 1. Клонируй репозиторий

```bash
git clone https://github.com/mvamks/Puls.git
cd Puls
```
### 2. Установи зависимости
```bash
npm install
```
### 3. Запусти проект
```bash
gulp
```
Откроется локальный сервер с live-reload по адресу: http://localhost:3000

## 🛠 Используемые технологии
* HTML5, SCSS (Sass), JavaScript

* Gulp 4: сборка проекта

* BrowserSync: live-reload

* gulp-sass, gulp-clean-css, gulp-htmlmin

* animate.css, WOW.js, Slick Slider
